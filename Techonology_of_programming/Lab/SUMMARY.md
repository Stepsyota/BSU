# Лабораторная 8 — Лифты

Симуляция СКУД лифтов: C++20, Qt6 Widgets, такт 50 мс.

Ветка `feature/elevator-animation` поверх табличного UI с `main`: вид здания, человечки, спавн с клавиатуры.

## Сборка и запуск

```bash
cd Techonology_of_programming/Lab
make          # последовательно, чтобы moc/g++ не раздували RSS
make run
make help
make clean
```

CLion может собирать через `CMakeLists.txt` (job pool `compile=2`). Нужен `pkg-config` и Qt6 Widgets.

## Домен

| Класс | Роль |
|--------|------|
| `Simulation` | сеанс: старт/пауза/стоп, такт, спавн, пожарка, сценарий |
| `Elevator` | кинематика v/a, двери 1 с, SCAN, счётчик поездок |
| `Person` | ожидание / поездка / высадка, таймаут 3 с на этаже |
| `FloorPanel` | вызовы с этажа |
| `MinWaitStrategy` / `MinIdleStrategy` | назначение лифта на вызов |
| `BuildingConfig` | этажи 1–20, лифты 1–5, v/a, вместимость |
| `Scenario` / `JsonStore` | JSON конфиг, сценарий, отчёт |
| `Statistics` | ожидание, поездки, холостые, пожарки |

Константы в `src/domain/include/Constants.h`. Живых людей не больше 80 (`kMaxLivingPeople`).

## UI

- `BuildingView` — этажи, кабины, человечки-палочки.
  - у человека: цифра «откуда» сверху справа, «куда» снизу справа;
  - в кабине заголовок `Лn  p/c  →этаж`, сетка 4×2 на 8 человек;
  - на этаже лишние не лезут на соседние — клип + `+N`.
- таблицы лифтов и людей справа;
- диалоги конфига и статистики;
- импорт/экспорт JSON, отчёт в `report.txt`.

## Клавиатура (спавн)

1. `Tab` — режим «создать человека», окно забирает клавиатуру.
2. `W`/`S` — этаж откуда; `Enter` — подтвердить.
3. `W`/`S` — этаж куда; `Enter` — создать.
4. `A`/`D` — соседний этаж. `Esc` — выход.

Ошибки спавна в status bar, без `QMessageBox` (иначе Enter и диалоги рекурсивно жрут память). Auto-repeat на Tab/Enter игнорируется. Фокус ушёл с окна — режим сбрасывается.
